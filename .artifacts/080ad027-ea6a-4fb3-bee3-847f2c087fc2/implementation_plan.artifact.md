# Implementation Plan - Next Vaccination Redesign

This plan outlines the redesign of the reminder system to move from an automatic, "Follow-up" based architecture to an explicit, "Next Vaccination" based architecture where the `reminders` table is the authoritative source of truth.

## User Review Required

> [!IMPORTANT]
> - The **automatic calculation** of future vaccinations based on history (ReminderEngine) will be **disabled**.
> - Next vaccinations must now be **explicitly scheduled** during the "Add Vaccination" process.
> - The `reminders` table will use a dual-ID system: a local UUID for sync identification and a server BIGINT (generated by Supabase) for database operations.

## Proposed Changes

### Data Models

#### [MODIFY] [ReminderEntity.kt](file:///C:/Users/Nadeem/Desktop/vaccine_manager_app/app/src/main/java/com/neochildclinic/data/local/entity/ReminderEntity.kt)
- **Stable ID Model**:
    - Keep `@PrimaryKey val id: String` (UUID) for local identification.
    - Keep `val serverId: Long?` to store the Supabase `BIGINT` primary key.
    - Ensure `val nxtVaccineId: List<String>?` is present.
- **Remote Mapping**:
    - Ensure `RemoteReminder` uses `val id: Long?` for serialization.
    - Ensure `toRemote()` maps `serverId` to `id` and **omits** `id` if `serverId` is null (to allow PostgreSQL to generate it).
    - Ensure `toLocal()` maps the server's `id` to `serverId`.

## Verification Plan

### Automated Tests
- Run `./gradlew :app:compileDebugKotlin` to verify the build.

### Manual Verification
1. **Explicit Scheduling**: Save a vaccination with a "Next Vaccination" scheduled. Verify it appears in the Due List.
2. **Authoritative Check**: Ensure NO vaccinations appear in the Due List unless they have a corresponding record in the `reminders` table.
3. **Sync Check**: Verify Supabase receives the record with a server-generated ID and the local app stores that ID in `serverId`.
4. **History Check**: Verify the Vaccination Card in history correctly shows "Next: <Type> • <Vaccines>" using the linked reminder.
