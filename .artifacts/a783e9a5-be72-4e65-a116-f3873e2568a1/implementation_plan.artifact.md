# Fix Audit Log Crash and Supabase Sync Error

This plan addresses two critical issues:
1.  **java.lang.IllegalArgumentException**: App crashes when parsing ISO 8601 timestamps in Audit Log and Clinical Notes.
2.  **NoSuchElementException (patientClinicId)**: Supabase sync fails because the `patientClinicId` column is missing from the `patients` table or there's a naming mismatch.

## User Review Required

> [!IMPORTANT]
> **Supabase Schema Update Required**
> The `patients` table in Supabase needs to be updated to include the `patient_clinic_id` column. Please run the following SQL in your Supabase SQL Editor:
> ```sql
> ALTER TABLE patients ADD COLUMN IF NOT EXISTS patient_clinic_id TEXT;
> ALTER TABLE patients ADD COLUMN IF NOT EXISTS registration_date TEXT;
> ```
